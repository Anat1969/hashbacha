# אפליקציית ניהול חוות דעת – אגף השבחה

אפליקציה מקצועית, מינימליסטית ו־RTL לניהול פרויקטים, בקשות וחוות דעת שמאיות על בסיס טבלת המקור בלבד.

## הפעלה מהירה

```bash
npm install
npm start
```

לאחר מכן לפתוח בדפדפן:

```text
http://localhost:3000
```

## קבצים מרכזיים

```text
public/index.html      ממשק המשתמש
public/styles.css      עיצוב מינימליסטי RTL
public/app.js          לוגיקת האפליקציה
public/data.js         נתוני מקור לפתיחה ללא שרת
server.js              שרת שמירה ו־API
server/config.js       הגדרות מייל
server/email.js        שליחת מייל אם SMTP מוגדר
data/projects.json     בסיס הנתונים הראשוני מתוך האקסל
SPEC.md                אפיון העבודה
```

## עריכה ושמירה

כאשר מפעילים דרך `npm start`, העריכות נשמרות בקובץ:

```text
data/projects.json
```

כאשר פותחים את `public/index.html` ישירות בלי שרת, האפליקציה עובדת במצב מקומי ושומרת בדפדפן באמצעות `localStorage`.

## מיילים

להפעלת שליחת מייל אמיתית יש ליצור קובץ `.env` לפי `.env.example` ולהגדיר SMTP.

ללא SMTP, האפליקציה לא ממציאה כתובות ולא שולחת אוטומטית. היא מכינה נוסח ומאפשרת פתיחת מייל דרך תוכנת הדואר.

## נאמנות למקור

הנתונים נמשכו מתוך הקובץ המצורף בלבד. עמודות `סטטוס רמזור` ו־`קישור` נוספו ריקות כי הן נדרשו בבקשה.
