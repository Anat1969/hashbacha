- **תוקן:**

  - נוספה בדיקה שכל קריאת בקרה שולחת `p_review`.
  - הוכח שהבדיקה נכשלת עם המבנה הישן.
- **אומת בשרת האמיתי** (בטרנזקציה שבוטלה): קליטת יזם ועירייה, מעבר ל"הדוחות נקלטו", שמירת קבצים, סימון, וצפייה בקוד צופה.

- **תוקן:**
  - `composeHref` ב־`src/lib/mail.js` עם מגבלות אורך: Gmail 6000, Outlook 1500, mailto 1800. מייל ארוך נפתח עם נמען ונושא בלבד, והנוסח המלא מועתק ללוח להדבקה (Ctrl+V).
  - `MailComposer`: פתיחה רק פותחת. מופיע "נשלח, לתייק" / "לא נשלח, חזרה לעריכה" / "סגירה בלי לתייק", ורק אישור מתייק `mail_out`.
  - בבקרה, אישור "נשלח" למכתב ההוראות מעביר ישירות ל"הוראות נשלחו". כפתור "נשלח מחוץ לאפליקציה" מיועד למכתב שנשלח בדרך אחרת.
